# Giant Beasts VS — cloud render

Render kit for the "สัตว์ยักษ์ VS" / Giant Beasts VS fight clips.
Push a `jobs/<id>/` folder with `job.json` and GitHub Actions renders it on 16 runners in parallel,
then publishes the finished clip, subtitles and chapters as a Release.

Run again by hand: Actions → render → Run workflow → job id.
